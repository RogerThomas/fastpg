# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report it privately through GitHub:
<https://github.com/RogerThomas/fastpg/security/advisories/new>.
Don't open a public issue.

## What to expect

You'll get a reply within a few days. Once a fix is ready it ships in a patch release, and the
advisory is published with it.
